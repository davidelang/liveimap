# Reading

Open a message from the list. From, To, the date, and the subject are at the top. The body is below the header.

## Back

Back returns to the list.

## Header

The header button hides or shows From, To, the date, and the subject.

## Images

On an HTML message, the image button shows or hides remote images. Images on a new HTML message start hidden.

## Reply

Reply answers the sender. Reply all answers the sender and the other recipients. Forward forwards the message.

## Delete

Delete follows the Deleting group: mark deleted, confirm before expunge, auto-expunge off.

## More

More holds Refresh, Save, Take address, and Customize toolbar. Save copies the message to another folder and leaves the original where it is.
