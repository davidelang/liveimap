# Writing

Compose starts a new message. Reply, Reply all, and Forward start from the open message. Send and Postpone are named, and the walk does not tap them. A new message can attach files.

![New message](images/phone/compose.jpg)

## Send

Send sends the message.

## Postpone

Postpone saves the message to send later.

## Back

Back on a message that was edited asks before discard.

## More

More holds the rest of the compose actions, including Customize toolbar.

Cc/Bcc shows the copy fields. To address book picks an address from the address book.

Wrap column and flowed text are under Compose. Import Pine settings and import or export settings are on the shared part of Settings. Import or export this account is on the account. The export leaves passwords out unless Include passwords in the export is turned on.
