# Folders

The folder list is the first screen after an account is open. INBOX is first. Search folders narrows the list.

![Menu](images/phone/drawer.jpg)

![Folder list](images/phone/folders.jpg)

## Menu

Menu opens the drawer. The account name opens that account's folder list. Inbox, postponed mail when a mailbox is set, and favorites are under the account. Then Settings, Manage addresses, Help, and About. Opening an Inbox checks that account. Each account keeps its own connection.

## Refresh

Refresh loads the folder list again.

## More

More holds Collapse all, Save as default view, Reset to default view, and Customize toolbar. Unsent is in More only while this phone holds mail that has not been sent. There is no picture of it.

## Compose

Compose starts a new message.
