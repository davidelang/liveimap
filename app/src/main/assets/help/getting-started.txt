LiveIMAP is an online IMAP client. Mail stays on the server. This phone does not keep a copy.

Open Settings, then Account. Set the IMAP host and port, the username, the password, and the email address. Under Mailboxes, set Sent, Postponed, Address book, and Spam.

Settings, Account, Import reads a .pinerc file.

When an IMAP host is set, About says the connection is not encrypted. The password and the messages travel in the clear.

Settings, Slower fallbacks, is off. Turn a switch on only when the server does not offer that feature. A large folder asks before LiveIMAP downloads a sort field or threading headers for every message.

Settings, Reading, Deleting: Confirm before expunge is on, and Auto-expunge is off. The Delete button follows that setting. Auto-expunge on sends CLOSE when you leave a folder.

The index sort lasts until you leave the app. Settings, Folders, holds the folder's usual sort. Threads start expanded unless Thread index is set to start collapsed.

The search icon searches the current folder. Subject is the usual field. Full text is not the simple search.

Advanced search combines terms with And or Or. Body and Full text search every message and are slow on a large folder.

Advanced search can cover this folder, the folders under it, subscribed folders, or every folder. Count returns the number and does not download messages.

The index Sort menu ends with Customize toolbar…. That screen moves Refresh, Search, and Filter onto the bar, into the menu, or out of sight.

The selection More menu ends with Customize toolbar…. That screen moves Mark read, Flag, Move, and Delete onto the bar, into that menu, or out of sight.

The folder list More menu ends with Customize toolbar…. That screen moves Refresh, Collapse all, Save as default view, and Reset to default view onto the bar, into that menu, or out of sight.

The reader More menu ends with Customize toolbar…. That screen moves Refresh and the message actions onto the bar, into that menu, or out of sight.

The compose More menu ends with Customize toolbar…. That screen moves Postpone onto the bar, into that menu, or out of sight.

In Customize toolbar…, drag a row to change its order. Move up, Move down, and Move to stay on the row.

Toolbar rows sets how many rows the bar may use. Actions that do not fit stay on the bar, and the last row scrolls.
