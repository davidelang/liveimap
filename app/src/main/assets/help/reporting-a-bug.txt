The debug report is optional. It contains the version and build, the Android version and device, the account settings with the password removed, the user name as <user> unless Show user name in the debug report is on, the last CAPABILITY lines, the connection-status history, and the tail of the traffic log. LiveIMAP does not send it. You copy or share it after you review it.
